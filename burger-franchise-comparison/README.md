# Burger Franchise Comparison — South Korea

## Project description
A mobile-friendly student research webpage comparing Lotteria, Burger King, and McDonald's in South Korea. It includes brand introductions, explicit comparison criteria, a table, four Google search queries, source links, and safe sorting controls that stay disabled when comparable numerical values are missing.

## Research source links

- Korea Public Data Portal, franchise brand information: https://www.data.go.kr/data/15110241/openapi.do
- Korea Policy Briefing, franchise statistics: https://m.korea.kr/briefing/pressReleaseView.do?newsId=156683272
- McDonald's Korea: https://www.mcdonalds.co.kr/
- Burger King Korea: https://www.burgerking.co.kr/
- Lotteria: https://www.lotteria.com/

## Research note
Publication date and data base year are different concepts. Total restaurant counts are not interchangeable with franchise-only counts. Do not rank values unless the metric, year, and definition are comparable.

## Run locally
Open `index.html` in a modern browser. No external APIs or JavaScript libraries are needed.
